## fastapi: O framework web para construir a API.
## uvicorn[standard]: O servidor ASGI que executa a  aplicação FastAPI.
## sqlalchemy: É o ORM (Object-Relational Mapper) que permitirá interagir com o banco de dados usando objetos Python em vez de SQL puro.
## psycopg2-binary: É o "driver" que permite que a SQLAlchemy se comunique especificamente com o PostgreSQL.
## alembic: É a ferramenta para gerir as migrações do esquema do banco de dados (criar tabelas, alterar colunas, etc.).
## python-dotenv: Ajuda a carregar variáveis de ambiente de um arquivo .env para o desenvolvimento local.
## google-cloud-secret-manager: Biblioteca da Google para acessar secrets de forma segura.
## pydantic-settings: Extensão do Pydantic para gerir configurações e variáveis de ambiente de forma estruturada.
